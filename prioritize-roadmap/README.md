# prioritize-roadmap

Reviewable prioritisation (RICE only when the inputs allow it) and an outcome-based Now/Next/Later roadmap with dependencies, capacity and commitment status. Deliverable: `output/roadmap-<slug>.md` with a download link.

## Files

- `skill.md`: the skill. English text; the document and the reply follow the member's language.
- `references/template.md`: document template, read on demand by the skill.
- `references/LICENSE.upstream.txt`: the upstream MIT licence, verbatim.
