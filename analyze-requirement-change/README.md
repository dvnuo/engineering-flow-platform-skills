# analyze-requirement-change

Impact analysis of a proposed requirement change against a supplied baseline: exact differences, trace to rules, stories, acceptance criteria, tests and dependencies, impact per area, decision options and the update list. Deliverable: `output/change-<slug>.md` with a download link.

## Files

- `skill.md`: the skill. English text; the document and the reply follow the member's language.
- `references/template.md`: document template, read on demand by the skill.
- `references/LICENSE.upstream.txt`: the upstream MIT licence, verbatim.

## Provenance

EFP-authored BA method. The baseline versioning, the trace status vocabulary, the per-area impact walk, the option comparison and the update list were written for EFP.
