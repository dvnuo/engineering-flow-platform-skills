# review-requirements-readiness

Evidence-based readiness review of requirements and stories with a `ready` / `needs-work` / `insufficient-evidence` verdict, severity-ranked findings and closing conditions; the sources are never modified. Deliverable: `output/readiness-<slug>.md` with a download link.

## Files

- `skill.md`: the skill. English text; the report and the reply follow the member's language.
- `references/template.md`: report template, read on demand by the skill.
- `references/LICENSE.upstream.txt`: the upstream MIT licence, verbatim.
